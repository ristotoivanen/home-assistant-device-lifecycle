## 4. High-risk conflicts and decisions requiring adjudication

1. **Historical minimalism vs surviving audit facts (OD-05).** Frozen 0.8.0 architecture suggests Purge removes A-owned history except a minimal reference, while surviving Purchases/Replacement edges may need tombstone targets. A blanket "retain everything" and a blanket "delete every reference" both violate aspects of this contract. Decide by collection and reference direction; never resolve by inference.
2. **Irreversible Purge vs old backups (OD-06).** Irreversible for the *continuing live dataset*, not global erasure across historical backups or Recorder. Clean-target restore of an older snapshot can create a new lineage with old Asset; never silently merge with post-Purge live tombstone state.
3. **All-or-nothing vs HA owner boundaries (OD-01/07).** User-visible completion can be atomic-in-effect only if an incomplete transaction cannot activate and reliably resumes/fails closed. A Store lock or compensating rollback alone cannot guarantee global durability.
4. **Lossless export vs confidential content (OD-03/12).** Arbitrary notes/URLs can contain secrets. Choose an exact sensitive backup and an explicit protection policy; do not silently redact and call the result restorable.
5. **Same-instance identity continuity vs portability (OD-04/10).** Canonical DL UUIDs are portable; a foreign HA `entity_id`, local device ID, RegistryEntry ID, user overrides or Recorder history are not automatically transferable.
